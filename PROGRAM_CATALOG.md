# Program catalog

The existing program catalog is preserved. `catalog:prepare` imports a current PUBLIC history version only when none exists, adds candidate official sources only for the original demo catalog, and never reseeds users/listings/balances or rewrites edited source settings.

Known-company sample rewards remain demo/unverified and unknown sharing permissions keep bounty activity disabled. Fictional demo programs can exercise the complete marketplace flow without implying company endorsement. Account-specific targeted offers and geographic/product variants have their own records and never replace the nationwide public offer.

See MONITORING.md for daily checks, confidence, source/history preservation, and manual review; TARGETED_OFFERS.md for private proof and expiration. Program permission edits remain administrator-only and audit logged. Public offer review does not silently grant sharing permission.
